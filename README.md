# FoodData Central - Nutrition Dashboard
## How to Run
pip install -r requirements.txt
streamlit run app.py

## Key Insights
- 170,000+ nutritional records
- 20 food categories, 233 nutrients
- Data from 2019 to 2026

## Charts Included
1. Pie Chart
2. Histogram
3. Line Chart
4. Bar Chart
5. Scatter Plot
6. Box Plot
7. Heatmap
8. Area Chart
9. Count Plot
10. Violin Plot
